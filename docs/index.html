A clear model

Useful estimates without false precision

Each dose is modeled independently with exponential caffeine clearance. The default half-life is 5 hours and can be adjusted. The app shows estimates, not blood measurements or guarantees about sleep.

remaining = dose × 0.5^(elapsed ÷ half-life)
